# Nearby-Stars · 邻近恒星目录

按 Gliese–Jahreiss（GJ）编号整理太阳邻域恒星资料，对照 CNS5、HD 和 HIP 编号，并补充多星系统组件、已确认系外行星、中文星名及资料来源。

项目始于 2023 年。CNS1 以 2024 年原稿为基础，整理 **GJ 1–915**；CNS2 为接续分卷，整理 **GJ 1000–1294**。两卷采用相同的十列纯文本格式。

**资料日期：CNS1 为 2026-10-15；CNS2 整理于 2026-10-16，行星数据使用 2026-10-15 已核查快照。**

| --- | ---: |
| GJ 整数编号覆盖 | 1–915，全部覆盖 |
| 小数编号 | 613 个 |
| 数据记录 | 2085 行 |
| 匹配的 NASA 已确认行星 | 312 颗 |
| 记录行星数的宿主或未分辨系统 | 180 行 |

包括编号范围内的小数条目，以及相关系统中拥有其他 GJ 编号的伴星。范围外的相关伴星跟随所属系统排列。

沿用原稿做法，保留距离超过 25 pc 的历史 GJ 条目，并在备注中说明。因此，这份目录**不能直接作为完整的 25 pc 恒星样本**。

“数据记录行数”不等于独立恒星数量：未分辨组件可能共享同一个来源条目，目录也保留了明确注明状态的历史记录。

## CNS2：GJ 1000–1294

新增 [CNS2 文件夹](CNS2/)，沿用十列格式，共 **368 行记录**，覆盖 GJ 1001–1294 的 **294 个已检索到的整数编号**，另列相关伴星。GJ 1000 未见于本次检索的三份星表，未补造条目。

本卷通过 **17 项检查**；2 行视差缺测、2 行使用历史测量，并明确注明 GJ 1103 B 在 SIMBAD 中被标为 `err`。GJ 1122 A/B 通过 Giclas 编号对应当前 CNS5 的 GJ 11355、11356。

NASA 接口本次返回 503，行星栏采用 2026-10-15 已核查快照，匹配 28 颗已确认行星；读取时间和接口情况均保留。详细口径、来源与缺口见 [CNS2 README](CNS2/README.md)。

各卷可能重复列出关联伴星，不能直接把行数相加作为独立恒星数量。CNS1、CNS2 是项目分卷名称，不代表历史星表版本。

## 列与单位

列顺序保持为：

```text
CNS5id  GJ  系外行星  HD  HIP  视差  距离  多星  组件  备注
```

| 列 | 含义 |
| --- | --- |
| CNS5id | CNS5 持续更新版编号。AB 等合并条目拆列后可共享编号，备注中说明；无独立条目时留空。 |
| GJ | Gliese–Jahreiss 编号，保留小数编号；`18.0` 等格式别名统一为 `18`。 |
| 系外行星 | 匹配 NASA Exoplanet Archive `pscomppars` 表的已确认行星数量。空白表示本次未匹配到记录，不代表没有行星。 |
| HD | Henry Draper 编号，按来源保留组件后缀。 |
| HIP | Hipparcos 编号。未分辨系统可能共享编号。 |
| 视差 | 单位 **mas**，正文保留两位小数。完整精度与误差见溯源记录。 |
| 距离 | 单位 **pc**，按完整精度视差计算 `距离 = 1000 / 视差`，结果保留两位小数。 |
| 多星 | `1` 表示来源记录多星、分光双星、多个组件或关联组件；`0` 表示本次来源没有明确的多星记录，不能据此证明为单星。关联组件是否物理束缚，以备注和来源为准。 |
| 组件 | 来源中的组件标签，如 A、B、Aa、Ab。无法取得独立名称的新条目以 `[CNS5 编号]` 识别。 |
| 备注 | 中文星名、恒星类型、系统关系、行星名称、共享测量说明、待核查状态和参考链接。 |

距离使用未舍入的视差计算，因此用正文中已经舍入的视差重新计算，可能相差 0.01 pc。这里采用简单倒数，未进行贝叶斯距离推断；视差误差较大的记录已注明。

褐矮星伴星沿用原稿做法列入组件。候选或已被否定的行星不补入已确认行星数量；未分辨宿主的行星按系统记录一次，避免重复计数。

## 来源与整理方法

1. **[CNS5 官方持续更新版](https://dc.zah.uni-heidelberg.de/tableinfo/cns5update.main)**：提供编号、系统关系、视差及文献出处。相关论文：[Golovin 等（2023）](https://doi.org/10.1051/0004-6361/202244250)。
2. **[SIMBAD](https://simbad.cds.unistra.fr/simbad/)**：补充交叉编号、天体类型及系统成员记录。匹配优先采用明确的编号对应关系，不直接以未经核查的最近邻代替识别。
3. **[CNS3 / VizieR V/70A](https://cdsarc.cds.unistra.fr/viz-bin/ReadMe/V/70A)**：核对历史条目及旧组件；只有旧测量值的记录明确注明年份和来源。
4. **[NASA Exoplanet Archive](https://exoplanetarchive.ipac.caltech.edu/)**：使用 `pscomppars` 已确认行星表，按宿主名称、唯一交叉编号或明确的宿主引用匹配。见[字段说明](https://exoplanetarchive.ipac.caltech.edu/docs/API_TD_columns.html)。
5. **[Stellarium 中文星名资料](https://github.com/Stellarium/stellarium/blob/master/skycultures/chinese/index.json)**：按 HIP 编号补充中文星名；见[名称来源说明](https://github.com/Stellarium/stellarium/blob/master/skycultures/chinese/description.md)。原稿已有名称也予以保留。

部分目录尚未充分表示的系统通过原始研究补充，例如 [HD 4747 B 褐矮星伴星](https://arxiv.org/abs/1604.00398)及其[后续研究](https://arxiv.org/abs/2208.01657)，以及 [13 Ceti 三星系统](https://ntrs.nasa.gov/citations/19760040940)。

不同来源的更新进度不同。“本版资料日期”表示本次读取与整理的时间，不表示所有观测都发生于这一年。原稿中的旧链接作为历史查证线索保留，不自动视为最新结论。

## CNS1 的核查与已知缺口

本版通过 **18 项检查**，覆盖编号范围、组合键去重、CNS5 编号有效性、来源视差一致性、距离计算、行星去重和若干已知错误的修正。具体结果见[核查记录](CNS1-checks.txt)。

仍有以下明确标注的资料缺口，类别之间可能重叠：

- **2 行**缺少可核查视差，视差与距离留空：GJ 559.1 B、GJ 611.3 B。
- **14 行**只能使用 CNS3 历史三角视差或系统继承值。
- **5 个旧组件**未能唯一匹配当前条目：GJ 84.2 B、GJ 321.3 C、GJ 656.1 BC、GJ 800 B、GJ 816.1 B。旧记录的真实性或物理关联状态也需要结合原始备注核查。

共享编号或系统视差不代表各组件具有独立测量。SIMBAD 中的关联记录也不一定足以证明物理束缚。当前资料整理未穷尽所有最新伴星论文；阅读或统计时应保留这些状态区别。

## 修订与贡献

欢迎通过 Issue 或 Pull Request 补充资料、纠正编号和完善组件识别。建议同时提供：

- GJ 编号和组件标签；
- 需要修改的字段及建议值，注明单位；
- 原始论文、官方星表或数据库条目链接；
- 资料日期，以及确认、候选、被否定或未分辨等状态。

更新数据时请同步维护溯源记录，保留旧备注及修改依据，避免将缺测值、候选关系或系统共享值改写成独立的确定测量。
